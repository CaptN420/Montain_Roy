## Issues

### Issue #1: Aucune faction ne commence avec un bâtiment de recherche

| Field | Value |
|-------|-------|
| **Severity** | 🔵 Low |
| **Category** | UX |
| **URL** | toutes factions (map locale) |

**Description:**
Aucune faction ne démarre sa partie avec le bâtiment de recherche attendu (`academy` humains/orcs, `temple` elfes, `workshop` nains). La recherche [T] devient donc impossible tant que le joueur n'a pas construit ce bâtiment, mais rien dans l'UI de départ ne l'indique clairement — le joueur peut appuyer sur [T] sans comprendre pourquoi "rien ne se passe".

**Steps to Reproduce:**
1. Démarrer une partie (n'importe quelle faction).
2. Appuyer sur la touche [T] (recherche).
3. Observer : message "Sélectionnez un bâtiment de recherche" sans indication de quoi construire.

**Expected Behavior:**
Le joueur comprend qu'il doit construire un bâtiment de recherche (académie/temple/atelier) pour rechercher — soit en démarrant avec ce bâtiment, soit via une indication UI claire dans le menu de construction.

**Actual Behavior:**
Le bâtiment de recherche est absent au départ et l'absence n'est pas visible dans l'UI (seul un message console informe). Vérifié : `human → AUCUN [academy]`, `orc → AUCUN [academy]`, `elf → AUCUN [temple]`, `dwarf → AUCUN [workshop]`.

**Screenshot:**
Voir `dogfood-output/screenshots/prod_human.png` (état de départ représentatif).

**Console Errors:**
Aucune exception (comportement voulu mais UX dégradée au démarrage).
